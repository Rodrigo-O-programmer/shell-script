# Script Feito Para Rodar em Debian 12


### O intuito de criar este script é aprender  fazendo.
O programa .sh é bem simples.
O programa mostra ao usuário se um pacote esta instalado e pergunta se ele quer instalar ou remover o mesmo.
A forma de uso deste programa em shell é: ./programa-installed.sh (programa). Ex:  ./programa-installed.sh nano
Vai aparecer um menu com algumas opçẽos de escolha.
#Menu
Deseja Instalar o Programa?
Deseja remover o programa?
Deseja Sair?
